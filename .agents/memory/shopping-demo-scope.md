name: ขอบเขต Shopping Demo
description: ข้อจำกัดที่ผู้ใช้กำหนดสำหรับ MVP ช้อปปิ้งตลาดไทย
---

เวอร์ชันแรกเป็นระบบ demo ที่ใช้งานได้ ใช้ภาษาไทยเป็นหลักและข้อมูล seed ภายในแอป ผู้ใช้กำหนดว่า “อย่าเชื่อม API ภายนอก อย่าสร้าง API key หรือ secret อย่าเรียกบริการ AI แบบมีค่าใช้จ่าย” และห้ามอ้างว่ามีการเชื่อม Shopee/Lazada/Affiliate จริง

**Why:** ผู้ใช้ต้องการทดลองระบบก่อน พร้อมโครงสร้างที่แยกส่วนเพื่อเชื่อมแหล่งข้อมูลที่ได้รับอนุญาตในภายหลัง

**How to apply:** คงข้อความแสดงสถานะข้อมูลตัวอย่าง ลิงก์ demo และผู้ช่วยที่แนะนำเฉพาะสินค้าภายในแอป ห้ามเปิดการเชื่อมต่อจริงโดยอาศัยการคาดเดาเจตนา

ผู้ใช้สั่ง “ห้าม publish สู่สาธารณะโดยอัตโนมัติ”

**Why:** ผู้ใช้ขอแอปจริงพร้อม preview แต่ยังไม่ขอเปิดใช้งานสาธารณะ

**How to apply:** ส่งมอบผ่าน preview เท่านั้น การเผยแพร่ต้องเป็นคำขอใหม่จากผู้ใช้

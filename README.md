# SHOPSHUD — ตลาดซื้อขายผลงานดิจิทัลและทรัพย์สินทางปัญญา

SHOPSHUD กำลังปรับทิศทางจากเดโมเปรียบเทียบสินค้าทั่วไป มาเป็นตลาดที่สมาชิกทุกคนเป็นได้ทั้งผู้ซื้อและผู้ขาย เพื่อซื้อขายผลงานสร้างสรรค์ เช่น เนื้อเพลง เพลง บีต งานศิลปะ eBook คอร์ส และไฟล์ดิจิทัล.

## หลักการผลิตภัณฑ์

- **บัญชีเดียว ซื้อได้และขายได้:** ไม่ต้องสมัครแยกบทบาท ผู้ใช้จัดการโปรไฟล์ผู้สร้างและซื้อผลงานจากบัญชีเดียวกัน
- **ไม่มีข้อมูลสินค้าสมมติ:** รายการสินค้า ราคา ยอดขาย รีวิว และสถิติ ต้องมาจากข้อมูลจริงที่ระบบบันทึกหรือแสดงสถานะว่าง ห้ามสร้างข้อมูลตัวอย่างที่ทำให้เข้าใจว่าเป็นรายการจริง
- **Preview ปลอดภัย:** ผู้สร้างเลือกตัวอย่างที่เปิดเผยได้ เช่น เนื้อเพลงบางท่อน เสียงตัวอย่างที่มีลายน้ำ ภาพความละเอียดต่ำ หรือสารบัญ โดยเก็บไฟล์ต้นฉบับไว้หลังการควบคุมสิทธิ์
- **ประเภทสิทธิ์ชัดเจน:** แยกการซื้อไฟล์ การให้สิทธิ์ใช้งาน และการโอนลิขสิทธิ์โดยชัดเจน การโอนสิทธิ์ต้องมีข้อตกลงเป็นลายลักษณ์อักษรที่ระบุผลงาน คู่สัญญา ราคา และขอบเขตสิทธิ์
- **สิทธิ์และความปลอดภัย:** ไม่เปิดเผยไฟล์ต้นฉบับผ่าน URL สาธารณะ ต้องมีการยืนยันตัวตน/สิทธิ์เข้าถึง การจัดการร้องเรียนละเมิดสิทธิ์ และประวัติธุรกรรม
- **ไม่มีการแสร้งว่าระบบพร้อม:** ห้ามแสดงปุ่มซื้อที่ไม่ทำธุรกรรมจริง ห้ามสร้างยอดขาย/รีวิว/สถิติปลอม และต้องแจ้งให้ชัดเมื่อฟีเจอร์ยังไม่พร้อม

## โครงสร้างเป้าหมาย

- `artifacts/chon-shopping` — เว็บแอป SHOPSHUD (ชื่อ workspace เดิมจะถูกเปลี่ยนเมื่อปรับโครงสร้างแพ็กเกจเสร็จ)
- `artifacts/api-server` — API ฝั่งเซิร์ฟเวอร์
- `lib/db` — schema และการเชื่อมต่อฐานข้อมูล
- `lib/api-spec` — สัญญา API

## ขอบเขต MVP

1. บัญชีผู้ใช้เดียวที่มีทั้งความสามารถซื้อและขาย
2. โปรไฟล์ผู้สร้างและหน้าร้าน
3. ลงรายการผลงาน พร้อมประเภทไฟล์ Preview ราคา และสถานะ
4. ตัวเลือกสิทธิ์และเอกสารการโอนสิทธิ์แยกตามรายการ
5. รายการผลงานที่ซื้อและการส่งมอบไฟล์อย่างมีการควบคุม
6. หลังบ้านสำหรับตรวจสอบรายการและจัดการข้อร้องเรียน
7. สถานะว่างที่ซื่อสัตย์เมื่อยังไม่มีผลงานจริง

## สถานะการพัฒนา

Repository นี้ยังอยู่ระหว่างการปรับโครงสร้างจากแอปเดิม การเขียนโค้ดหรือคอมมิตไม่ได้แปลว่าระบบพร้อมรับชำระเงินจริง การใช้งานจริงยังต้องมีการยืนยันตัวตน การจัดเก็บไฟล์ที่ปลอดภัย ฐานข้อมูลที่ตั้งค่าแล้ว ระบบชำระเงิน/จ่ายเงินที่รองรับ marketplace การทดสอบ และการตรวจเอกสารทางกฎหมาย.

อย่าใส่ API key, secret, ไฟล์งานของลูกค้า หรือข้อมูลส่วนบุคคลไว้ใน repository

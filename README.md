# SHOPSHUD — ร้านค้าผลงานและทรัพย์สินทางปัญญาของเรา

SHOPSHUD เป็นร้านค้าออนไลน์ของแบรนด์เราเอง ไม่ใช่ตลาดกลาง ไม่มีระบบให้บุคคลทั่วไปเปิดร้านหรือส่งผลงานมาลงขาย สินค้าทุกชิ้นต้องเป็นผลงานของเรา หรือเป็นสินทรัพย์ที่เรามีสิทธิ์จำหน่ายอย่างถูกต้อง

## แนวทางผลิตภัณฑ์

- **ร้านเดียว เจ้าของผลงานรายเดียว:** มีบัญชีผู้ดูแลร้านสำหรับจัดการแคตตาล็อก คำสั่งซื้อ และเนื้อหา ลูกค้าสมัครหรือเข้าสู่ระบบเพื่อซื้อและเข้าถึงสิ่งที่ซื้อได้ แต่ไม่มีความสามารถเปิดร้านหรือลงขาย
- **ขายเฉพาะผลงานที่มีจริง:** ไม่แสดงสินค้าตัวอย่าง ราคา รีวิว ยอดขาย หรือสถิติปลอม หากยังไม่มีรายการจริง ให้แสดงสถานะว่าง
- **หมวดหมู่เริ่มต้น:** เพลงและเนื้อเพลง, บีต/ดนตรี/เสียง, eBook/คู่มือ/คอร์ส, งานออกแบบและสินทรัพย์ดิจิทัล
- **Preview อย่างปลอดภัย:** ผู้ดูแลเลือกตัวอย่างที่เผยแพร่ได้ เช่น เนื้อเพลงบางท่อน เสียงตัวอย่างที่มีลายน้ำ ภาพความละเอียดต่ำ หรือสารบัญ ไฟล์ต้นฉบับต้องเก็บในพื้นที่ที่ไม่เปิดสาธารณะและส่งมอบเฉพาะผู้ซื้อที่มีสิทธิ์
- **เงื่อนไขสิทธิ์ชัดเจน:** แยกการซื้อไฟล์ สิทธิ์ใช้งาน และการโอนลิขสิทธิ์ การโอนลิขสิทธิ์ต้องใช้ข้อตกลงเป็นลายลักษณ์อักษรที่เหมาะสมกับกฎหมายและระบุผลงาน คู่สัญญา ราคา และขอบเขตสิทธิ์
- **ไม่จำลองธุรกรรม:** ปุ่มซื้อและสถานะคำสั่งซื้อจะต้องเชื่อมกับระบบจริงก่อนเปิดใช้ หากระบบชำระเงินยังไม่พร้อม ให้ระบุว่ายังไม่เปิดขายแทนการแสร้งว่าซื้อสำเร็จ

## ขอบเขต MVP

1. หน้าร้านแบรนด์ SHOPSHUD และหน้ารายละเอียดผลงาน
2. บัญชีลูกค้าและคลังผลงานที่ซื้อ
3. หลังบ้านผู้ดูแลร้านสำหรับเพิ่ม แก้ไข และนำสินค้าของเราออกเผยแพร่
4. หมวดหมู่ ราคา Preview และรายละเอียดสิทธิ์การซื้อ
5. การชำระเงินจริงและส่งมอบไฟล์อย่างปลอดภัย ก่อนประกาศเปิดขาย
6. เอกสารสิทธิ์/สัญญาสำหรับรายการที่ขายขาดลิขสิทธิ์

## โครงสร้างทางเทคนิค

- `artifacts/chon-shopping` — เว็บแอป (ยังต้องย้าย UI เดิมจากร้านเปรียบเทียบสินค้าทั่วไป)
- `artifacts/api-server` — API ฝั่งเซิร์ฟเวอร์
- `lib/db` — schema และการเชื่อมต่อฐานข้อมูล
- `lib/api-spec` — สัญญา API

## สถานะ

Repository นี้อยู่ระหว่างการปรับโครงสร้าง ยังไม่ได้หมายความว่าร้านค้าพร้อมรับเงินหรือส่งมอบไฟล์จริง ต้องย้ายหน้าจอและลบข้อมูลจำลองจากทุกหน้า ตั้งค่าฐานข้อมูลและ migrations พัฒนาการยืนยันตัวตน การจัดเก็บไฟล์ การชำระเงิน ทดสอบ และตรวจเงื่อนไขทางกฎหมายก่อนเปิดใช้งาน

ห้ามใส่ API key, secret, ไฟล์งานส่วนตัว หรือข้อมูลลูกค้าใน repository

# ช้อปชัด — Shopping MVP (Demo)

เว็บแอปภาษาไทยสำหรับทดลองค้นหาสินค้าหลายร้านจำลอง กรองหมวดหมู่และงบประมาณ เรียงผลลัพธ์ เปรียบเทียบสูงสุด 3 รายการ และใช้ผู้ช่วยเลือกสินค้าจากแค็ตตาล็อกภายในแอป

## สถานะเดโม

- สินค้า ร้านค้า ราคา และสถิติเริ่มต้นเป็นข้อมูลสมมติ ไม่ใช่ข้อเสนอขายหรือราคาปัจจุบัน
- ไม่ได้เชื่อม Shopee, Lazada, เครือข่าย affiliate หรือ API ภายนอก
- ผู้ช่วยใช้กฎและข้อมูลสินค้าภายในแอป ไม่ใช่โมเดล AI และไม่เรียกบริการแบบมีค่าใช้จ่าย
- ปุ่มซื้อเป็นการสาธิต โดยแสดงคำเตือนก่อนเปิด `example.com` ไม่มี affiliate link ที่ใช้งานจริง
- หน้าผู้ดูแลเป็นหน้าสาธิตสาธารณะ ไม่ใช่ระบบ admin ที่มีการยืนยันตัวตน
- สถานะเปรียบเทียบและตัวนับการทดลองใช้เก็บเฉพาะในเบราว์เซอร์ ไม่ส่งไปบริการ analytics ภายนอก ไม่ซิงก์ข้ามอุปกรณ์ และอาจหายเมื่อผู้ใช้ล้างข้อมูลเว็บไซต์
- ภาพสินค้าเป็นภาพประกอบ ไม่ใช่หลักฐานของสินค้าหรือคุณสมบัติจริง

## ทดลองใช้งาน

เปิด Preview ของ **ช้อปชัด — AI Shopping Demo** ใน Replit แล้วลองค้นหาคำไทยหรืออังกฤษ กรองงบ เลือกเปรียบเทียบ และเปิดผู้ช่วยเลือกสินค้า ไม่มีบัญชีหรือ API key ที่ต้องตั้งค่า

ตัวแอปอยู่ใน `artifacts/chon-shopping` แยกข้อมูลสินค้า ตรรกะค้นหา/แนะนำ และส่วนแสดงผลเพื่อให้เปลี่ยนเป็นแหล่งข้อมูลที่ได้รับอนุญาตในภายหลังได้ โดยยังไม่ต้องเชื่อมบริการจริงในเวอร์ชันนี้

สำหรับผู้พัฒนา: ใช้ workflow `artifacts/chon-shopping: web` เพื่อรัน preview และ `pnpm --filter @workspace/chon-shopping run typecheck` เพื่อตรวจ TypeScript

## ก่อนเปิดให้ใช้งานจริง

1. สมัครและได้รับอนุมัติโปรแกรม affiliate ของแต่ละเครือข่าย พร้อมตรวจเงื่อนไขการใช้แบรนด์และการเปิดเผยค่าคอมมิชชัน
2. เชื่อมเฉพาะ API, feed หรือข้อมูลที่เจ้าของอนุญาต รวมถึงสิทธิ์ใช้ภาพสินค้า ห้ามดึงข้อมูลโดยไม่มีสิทธิ์
3. ตรวจราคา สต็อก ค่าจัดส่ง ลิงก์ปลายทางและ tracking พร้อมระบุเวลาที่อัปเดตและรองรับข้อมูลหมดอายุ
4. เปลี่ยนหน้าสถิติจำลองเป็นระบบที่ตรวจสอบได้ เพิ่มการยืนยันตัวตนและสิทธิ์ผู้ดูแลฝั่งเซิร์ฟเวอร์
5. จัดทำนโยบาย privacy และการเก็บ/ลบข้อมูลให้สอดคล้อง PDPA ประเมิน consent ก่อนเพิ่ม cookies หรือ analytics
6. หากเพิ่ม AI จริง ให้จำกัดคำตอบกับข้อมูลที่ตรวจสอบได้ ประเมินความถูกต้อง ค่าใช้จ่าย และความเป็นส่วนตัวก่อน
7. ทดสอบการใช้งานจริงบนมือถือ คีย์บอร์ด โปรแกรมอ่านหน้าจอ รวมถึงความปลอดภัยและความถูกต้องของการนับคลิก
